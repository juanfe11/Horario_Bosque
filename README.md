# Horario\_Bosque

Proyecto universitario de la materia **Proyecto Núcleo**: una página web que reúne los horarios de la universidad en un solo lugar.

```
├── backend/     # API / servidor
├── frontend/    # Interfaz de usuario
├── .gitignore

```

## Instalación y ejecución

### 1\. Clonar el repositorio

```bash
git clone https://github.com/juanfe11/Horario\\\_Bosque.git
cd Horario\\\_Bosque
```

### 2\. Backend

```bash
cd backend
# instalar dependencias (ejemplo con Node)
npm install
# copiar variables de entorno y completarlas
cp .env.example .env
# iniciar el servidor
npm start
```

### 3\. Frontend

```bash
cd frontend
npm install
npm start
```

## Variables de entorno

Los archivos `.env` **no se suben** a GitHub. Usa `.env.example` como guía y pide los valores reales al equipo.

## Flujo de trabajo en equipo

1. Antes de empezar: `git pull`
2. Crear una rama propia: `git checkout -b feature/nombre-del-cambio`
3. Hacer cambios y commits con mensajes claros:

```bash
   git add .
   git commit -m "Descripción clara del cambio"
   ```

4. Subir la rama: `git push -u origin feature/nombre-del-cambio`
5. Abrir un **Pull Request** en GitHub para que el equipo lo revise antes de unirlo a `main`.
